Install help

Set up Mac n Droid, step by step.

Installing on a Mac and an Android phone takes about two minutes. If something gets in the way, the fix is almost always on this page.

Before you start

  • A Mac with macOS 14 Sonoma or later (Apple silicon or Intel). A Windows 10 or 11 PC, or a Linux computer, works too, in beta.
  • An Android phone with Android 10 or later, any brand.
  • Both on the same Wi‑Fi network. No account and no internet connection between them is needed.

Install on your Mac

  1. Download MacNDroid-x.y.z.dmg from the download section or GitHub Releases.
  2. Open the file and drag Mac n Droid into Applications.
  3. Open Mac n Droid from Applications. The first time, macOS says it can't be opened, because the app isn't notarized by Apple yet. Open System Settings → Privacy & Security, scroll down and click Open Anyway. You only do this once.
  4. Click Allow when macOS asks for Local Network and Notifications. Mac n Droid needs the local network to find your phone.

After that, the Mac app keeps itself up to date.

MacThe phone can't find the Mac

Check System Settings → Privacy & Security → Local Network and make sure Mac n Droid is turned on.

Install on Android

  1. On the phone, download MacNDroid-x.y.z.apk from the download section and open it.
  2. If Android asks, allow Install unknown apps for the browser or Files app you opened it from, then tap Install.
  3. Open Mac n Droid, tap Get started and turn on the features you want. Each one asks for its permission only when you switch it on.

Mac n Droid will be on Google Play soon. Until then, install the APK and install new versions over the old one.

Android"App blocked to protect your device"

Google Play Protect blocks apps from outside the Play Store that ask for SMS, notification or accessibility access. Open the Play Store → your profile picture → Play Protect → ⚙ → turn off Scan apps with Play Protect, install Mac n Droid, then turn it back on. Mac n Droid keeps working.

AndroidNotification access is greyed out

On Android 13 and later, apps installed from outside the Play Store need one extra step: Settings → Apps → Mac n Droid → ⋮ → Allow restricted settings. Then turn on notification access again.

AndroidIt disconnects when the phone is locked

On Samsung, Xiaomi, OnePlus, Oppo and some others, set Mac n Droid's battery use to Unrestricted and allow it to start by itself. dontkillmyapp.com shows the exact steps for each brand.

Pair your phone

  1. On the Mac, open Mac n Droid. The first time, it shows a QR code. Later you'll find it under Pair a Phone.
  2. On the phone, open Mac n Droid and tap Scan QR code, then point the camera at the code.
  3. That's it. Both devices say they're connected, and from then on they find each other by themselves.

Mac n Droid works with one phone at a time. If a different phone scans the code, it waits until you allow it on the Mac or on the phone that's already paired.

If they don't connect

  • Same network: both need to be on the same Wi‑Fi. Guest networks and some office networks keep devices apart, so try your main home network.
  • VPN: a VPN on the phone or the computer can hide them from each other. Pause it and try again.
  • Mac: make sure Mac n Droid is allowed under System Settings → Privacy & Security → Local Network.
  • Android 17: if Android blocks Mac n Droid from your Wi‑Fi network, the app says so and asks for local network access. Allow it.
  • Still nothing? Restart Mac n Droid on both devices. If you changed networks, they reconnect by themselves within a few seconds.

Windows (beta)

  1. Download the installer from GitHub Releases: -x64.exe for most PCs, or -arm64.exe for ARM laptops. A portable zip without an installer is there too.
  2. Windows isn't sure about new apps yet and shows "Windows protected your PC". Click More info → Run anyway.
  3. The first time it starts, allow it on Private networks when Windows Firewall asks. Then pair your phone the same way as on a Mac.

Linux (beta)

Download the Flatpak from GitHub Releases (x86_64, or aarch64 for ARM computers), then:

flatpak install --user MacNDroid-*-Linux-x86_64.flatpak flatpak run app.macndroid.Linux
LinuxThe phone can't reach the computer

Fedora and some other distributions block incoming connections. Allow TCP port 47800:

sudo firewall-cmd --add-port=47800/tcp --permanent sudo firewall-cmd --reload

Browser extension (optional)

Control music and videos in your browser from your phone, and send pages to your phone. Works in Chrome, Edge, Firefox, Brave, Arc and other Chrome-based browsers.

  1. In Mac n Droid on your computer, click Browser Extension in the sidebar.
  2. Click Add to Chrome-Based Browser or Add to Firefox-Based Browser. The store opens in your browser; click Add there.

Still stuck?

Email help.macndroid@gmail.com or open an issue on GitHub. Say which phone, which computer and what you see, and we'll help.
