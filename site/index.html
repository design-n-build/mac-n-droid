Set up in a minute.

Install both apps, scan a code, and you're done.

  1. Install on your Mac.Open the DMG and drag Mac n Droid to Applications. The first time, go to System Settings → Privacy & Security and click Open Anyway.
  2. Install on your phone.Open the APK and allow installing from your browser or file manager.
  3. Pair.On the Mac, choose Pair a Phone. On the phone, tap Scan QR code.
  4. Allow access.Follow the Finish setup list on the phone. If notification access is greyed out, open App info → ⋮ → Allow restricted settings.
