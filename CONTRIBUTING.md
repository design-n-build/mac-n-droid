# Contributing to Mac n Droid

Thanks for helping! Mac n Droid is a free, open-source app that connects Android phones and Macs.

## Reporting bugs and ideas
Use **Issues → New issue** and pick *Bug report* or *Feature idea*. Search existing issues first; if
someone already reported it, add a 👍 reaction or a comment with your phone and Mac details.

## Design rules
- **Native design only.** The Mac app follows Apple's Human Interface Guidelines; the Android app
  follows Material 3. No custom design language.
- Everything stays **local**: no accounts, no cloud, no analytics.

## Code changes
1. Open an issue first for anything bigger than a small fix, so we can agree on the approach.
2. Fork the repo, make your change on a new branch, and open a pull request.
3. Explain what you changed and how you tested it on a real phone and Mac.

Build instructions are in the [README](README.md#build-from-source). The phone ↔ Mac messages are
described in [PROTOCOL.md](PROTOCOL.md).
